# reports/

Generated by the evaluation scripts — never hand-edit:

- `sms_metrics.json`, `url_metrics.json` — precision/recall/F1/ROC-AUC/
  confusion matrix, written by `ml/evaluation/evaluate_sms.py` / `evaluate_url.py`
- `sms_confusion_matrix.png`, `url_confusion_matrix.png`
- `sms_dataset_stats.json`, `url_dataset_stats.json` — actual (never
  estimated) dataset statistics, written by the training scripts
- `model_comparison.md` — fill in manually when comparing TF-IDF vs
  DistilBERT vs RoBERTa (see docs/MODEL_CARD.md)
