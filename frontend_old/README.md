# frontend/ (Phase 2 — not built in Phase 1)

Per the project's phase discipline, Phase 1 is backend-only. This
directory is a placeholder so the intended structure (React + TypeScript
+ Vite, matching `backend/models/schemas.py::AnalysisReport`) is visible,
without pulling frontend work into the one-month Phase 1 deadline.

When Phase 2 starts, the backend API (`docs/API.md`) is already stable
and complete enough to build against — no backend changes should be
required to build the dashboard, scanner, and result pages described in
the original project spec.
